# 酒馆助手：变量与宏

本文档整理自酒馆助手官方文档，供 AI 与开发者参考。涉及变量类型、获取/修改变量、酒馆助手宏及「以 `$` 开头的键不发给 AI」等约定。

**文档根**: https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/

---

## 一、变量类型

酒馆仅提供全局、聊天、扩展三类变量，酒馆助手扩展后支持更多类型。在获取或修改变量时，需在 `VariableOption` 中指定要操作的变量类型。

```ts
type VariableOption = {
  type: 'global' | 'preset' | 'character' | 'chat' | 'message' | 'script' | 'extension';
  // 根据类型不同可能有其他参数，例如 message 需 message_id
};
```

| 类型 | 说明 | 宏（在提示词/楼层中获取） |
|------|------|---------------------------|
| **global** | 绑定在用户存档上，全局可用 | `{{get_global_variable::变量}}` |
| **preset** | 绑定在某个预设上，可随预设导出 | `{{get_preset_variable::变量}}` |
| **character** | 绑定在角色卡上，可随角色卡导出；未打开角色卡会报错 | `{{get_character_variable::变量}}` |
| **chat** | 绑定在某个聊天文件上，可随聊天导出 | `{{get_chat_variable::变量}}` |
| **message** | 绑定在聊天文件的某个消息楼层上；需 `message_id: number \| 'latest'`，负数为深度索引，`-1` 为最新楼层 | `{{get_message_variable::变量}}` / `{{format_message_variable::变量}}`（仅最新楼层） |
| **script** | 绑定在某个脚本上；需 `script_id: string`，脚本内可用 `getScriptId()` | 在「酒馆助手-脚本库」中编辑脚本时可手动修改 |
| **extension** | 绑定在用户存档上，按扩展 ID 分区；需 `extension_id: string` | — |

- 消息楼层变量：`message_id` 超出 `[-chat.length, chat.length)` 会抛错。
- 参考：[变量类型](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/功能详情/变量/变量类型.html)

## 二、获取变量

### getVariables

获取变量表。

```ts
function getVariables(option: VariableOption): Record<string, any>
```

**示例**

```ts
// 获取所有聊天变量
const variables = getVariables({ type: 'chat' });

// 获取全局变量并判断是否存在
const variables = getVariables({ type: 'global' });
if (_.has(variables, "神乐光.好感度")) { /* ... */ }

// 获取倒数第二楼层的消息楼层变量
const variables = getVariables({ type: 'message', message_id: -2 });

// 脚本内获取本脚本变量
const variables = getVariables({ type: 'script', script_id: getScriptId() });
```

参考：[获取变量](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/功能详情/变量/获取变量.html)

## 三、替换或修改变量

### replaceVariables

完全替换变量表。

```ts
function replaceVariables(variables: Record<string, any>, option?: VariableOption): Record<string, any>
```

示例：先 `getVariables`，用 lodash 处理后再 `replaceVariables`；或直接传入新对象替换。

### updateVariablesWith

用函数更新变量表。

```ts
function updateVariablesWith(
  updater: (variables: Record<string, any>) => Record<string, any> | Promise<Record<string, any>>,
  option: VariableOption,
): Record<string, any> | Promise<Record<string, any>>;
```

### insertOrAssignVariables

插入或修改变量：不存在则新增，存在则修改。

### insertVariables

仅插入新变量：已存在的键不覆盖。

### deleteVariable

按路径删除变量，不存在则不操作。

```ts
function deleteVariable(variable_path: string, option: VariableOption): { variables: Record<string, any>; delete_occurred: boolean };
```

参考：[替换或修改变量](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/功能详情/变量/替换或修改变量.html)

## 四、酒馆助手宏

酒馆自带宏（如 `{{user}}`、`{{char}}`、`{{getvar::变量}}`）难以让扩展注册带参数的宏。酒馆助手因此提供**酒馆助手宏**，可在提示词或楼层文本中按路径取变量。

### 内置宏

- **`{{get_xxx_variable::变量}}`**：获取指定类型变量在 `变量` 路径下的值，**显示为一行 JSON 字符串**。  
  `xxx` 可为：`global`、`preset`、`character`、`chat`、`message`。
- **`{{format_xxx_variable::变量}}`**：同上，但**显示为格式化后的 YAML 块**，AI 更易理解。

发给 AI 时**应优先使用 `{{format_xxx_variable::变量}}`**，而非 `{{get_xxx_variable::变量}}`。例如变量框架中常用 `{{format_message_variable::stat_data}}` 把 `stat_data` 发给 AI。

### 以 `$` 开头的键不发给 AI

**`{{get_xxx_variable::变量}}` 与 `{{format_xxx_variable::变量}}` 会忽略变量对象中所有以 `$` 开头的键。**  
因此可在变量里存「不该给 AI 看」的数据。例如：

- 变量内容：`{ $meta: {}, 好感度: 0 }`
- 宏得到的输出：`{ 好感度: 0 }`（不包含 `$meta`）

在 schema 中用 `$birthday`、`$flag` 等命名即利用此特性，表示该字段不随提示词输出、AI 不可见。

### 禁用酒馆助手宏

在「酒馆助手主界面-禁用酒馆助手宏」中可关闭宏解析，使 `{{get_message_variable::stat_data}}` 等原样显示并发送给 AI。

### 自定义宏：registerMacroLike

```ts
function registerMacroLike(
  regex: RegExp,
  replace: (context: MacroLikeContext, substring: string, ...args: any[]) => string,
): RegisterMacroLikeReturn;

type MacroLikeContext = {
  message_id?: number;
  role?: 'user' | 'assistant' | 'system';
};

type RegisterMacroLikeReturn = { unregister: () => void };
```

- `regex`：匹配的正则。
- `replace`：对匹配文本的替换函数，返回值为替换结果。
- 返回值的 `unregister()` 可取消注册。

取消注册：`unregisterMacroLike(regex: RegExp)`。
