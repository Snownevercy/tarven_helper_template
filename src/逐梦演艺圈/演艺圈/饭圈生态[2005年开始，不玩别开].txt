<rule_饭圈生态>
触发条件: [世界.当前时间] >= 2005。

组织架构:
  - 经纪公司(操盘手): 雇佣脂粉(职业粉丝)建立后援会，发布数据任务套牢散粉，制造虚假数据指标获取商业代言。
  - 粉头/大粉: 组织集资与打投的意见领袖。存在携款跑路、倒卖艺人行程的灰产行为。
  - 数据女工(散粉): 控评、买号刷数据、购买代言产品的免费劳动力。
  - 站姐/代拍: 购买黄牛行程蹲守拍摄，贩卖PB(照片集)与独家生图赚取差价。可能导致剧组造型提前泄露(触发违约)或机场安全事件。
  - 私生粉: 跟踪、窃听、蹲守酒店，直接干扰艺人行程。
  - 黑粉/对家粉: 挖掘黑历史、组织打低分与负面通稿。

核心机制:
  数据刷榜: 数据站下发任务→粉丝多账号轮播→形成榜单数据→吸引资本投放。
  反黑举报: 批量利用平台规则举报对家内容，推动账号或作品下架。
  应援集资: 借生日/打投名义开启集资→购买大屏广告/抛弃式商品换选票(如倒牛奶)。
  灰产: 航班/通告信息泄露→黄牛倒卖→站姐进禁区拍摄→制作PB在超话预售。

提纯战:
  触发: User参演CP向/双主角剧集且完结上映。
  三步流程:
    1. 解绑: 取消双人商务，公开场合减少互动，双方团队发通稿撇清。
    2. 信息战: 双方大粉组织挖掘对家负面，刷黑词条。
    3. 虐粉固粉: 发布受害通稿，刺激粉丝加大集资打投。
  风险: 若攻击超出平台阈值引起广泛关注→官媒点名→双方待播作品临时撤档。

饭圈黑话(生成网络评论时强制使用):
  - 动作类: 打投(花钱投票) / 控评(控制评论区) / 屠版(刷屏) / 洗广场(好评覆盖负面) / 提纯(CP粉转唯粉) / 跨火盆(清除对家痕迹) / 爬墙（换偶像）
  - 称呼类: 脂粉(职业粉丝) / 皮下(账号运营者) / 对家(竞品) / 糊咖(不红艺人) / 皇族(公司偏爱者) / 墙头粉(无固定偶像，频繁爬墙换人的粉丝) / 本命(即最喜欢的偶像)

时代分期:
  2005-2013_初代: 贴吧/论坛聚集，短信投票，排他性雏形。
  2014-2017_流量时代: 引入韩国打榜应援体系，流量数据直接绑定影视番位与代言。CP捆绑营销兴起。
  2018至今_工业化: 选秀投票与付费产品强制绑定。提纯撕逼成为常规营销。灰产(PB/代拍)形成产业链。

叙事干预(NPC逻辑锁):
  - IF User有前台属性(演员/歌手/偶像) → 经纪人/公司高层必须在对话中主动提及粉丝维稳、数据要求或粉群提纯方案。
  - IF User是导演/编剧 → 合作方艺人团队将"粉丝是否接受此情节/番位"作为修改剧本的谈判筹码。
  - IF User存在竞品且对方咖位>=二线 → 对方粉丝必然主动发起攻击(打低分/刷黑词条/通稿拉踩)。

反噬机制:
  恋情/人设崩塌: 触碰粉丝底线(公开恋情/负面私生活/核心人设崩塌) → 核心粉丝流失、大规模脱粉回踩、前期隐秘黑料被自曝。含道德/恋爱条款的合同同时触发商业违约索赔。

  政策打压(强制触发):
    红线: 集资千万级 / 未成年人借贷打投 / 恶意举报致出圈大事件 / 严重社会资源浪费(如倒牛奶)。
    命中红线 → 无视团队危机转移，立即触发官方打压，严禁稀释后果。
    时代匹配:
      [2005-2017] → 广电红头文件/央视点名。
      [2018-2020] → 紫光阁、共青团中央官微点名/约谈平台。
      [2021-] → 网信办"清朗行动"专项整治。
    后果: 商业代言批量解约、作品下架、社交账号禁言。
