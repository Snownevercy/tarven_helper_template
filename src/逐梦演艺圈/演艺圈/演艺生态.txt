<rule_演艺生态>
演艺生态规则:
  对剧情所有角色生效，系统评估其身份状态并驱动行为。

  模块一_身份映射:
    前置扫描:
      - 扫描目标角色的 [持股比例] + [行业地位] + [契约状态]，映射至三个生态位之一。
      - User状态额外扫描 [专业评估.当前咖位] 与 [人脉.社交版图]，综合加权后映射。
      - 提出合作的一方默认已对合作方完成专业评估。

    Branch_A_决策层:
      - 定义: 掌握生产资料或资本的一方 (资方/老板/投资人)。
      - 核心逻辑: [所有权与庇护]。拥有人事任免与战略定义的最终决定权，同时承担项目失败的全部资金损失与法律连带责任。须履行开发责任(资源匹配/危机公关/财务及时结算)，违约构成艺人解约的法律依据。

    Branch_B_合作层:
      - 定义: 携带稀缺资源入局的一方 (股东/带资进组/技术入股)。
      - 核心逻辑: [博弈]。对涉及自身利益的核心条款拥有否决权，享有分红等资本性收益。必须完成承诺的资源对赌，否则触发降级。

    Branch_C_雇佣层:
      - 定义: 出卖劳动或形象的一方 (签约艺人/普通职员)。
      - 核心逻辑: [契约]。享有合同约定的薪酬与推广资源，必须接受调度安排与竞业禁止。

  模块二_契约与解约:
    常见契约类型:
      - 全代理契约: 长约捆绑，公司占有艺人全部商业活动的代理权与高额分成。
      - 项目聘用约: 短期雇佣，按项目/档期结算。
      - 形象授权约: 肖像权授权+排他竞业，违约索赔。
      - 劳务通告约: 按期结算，配合台本执行。

    解约诉讼_事实冻结:
      - 经纪约纠纷进入仲裁/诉讼后，原公司可申请行为保全禁令限制艺人签署新约。即使未获禁令，新合作方因诉讼风险普遍拒绝接手，艺人处于事实冻结状态，通常持续6个月至2年。
      - IF 发起解约诉讼 -> 冻结期内无法正常接工作，仅允许履行存量合同。强制描写收入断流、社交圈观望、竞品趁机抢占资源。

  模块三_经纪人归属逻辑:
    - 独立经纪人: 仅对雇主个人负责。雇主利益 > 市场规则。
    - 公司指派经纪人: 对经纪公司负责。公司指令 > 艺人诉求。
    - 商业合伙人型: 对资本增值负责。股价/资产 > 短期情绪。

  模块四_财务强制结算:
    逻辑总纲:
      - 凡涉及 [签约/项目发布/通告结束/违约]，必须执行资金结算。
      - 结算公式: (收入总额 - 公司抽成 - 税务) = 个人入账。资方模式额外扣除团队运营成本。(→:::bank, :::contract)

    结算触发场景:
      - 签约时: 新人描写预支安家费/生活费; 高咖位描写签字费到账。
      - 杀青/录制结束: 执行结算公式，确认资金变动。
      - 违约/赔偿: 立即扣除对应金额。[主角.资本] 不足则触发负债剧情(抵押资产/借高利贷)。
      - 长尾收益: 票房分红通常滞后3-6个月结算，版税按季度或半年结算。分红未到账期间的现金流压力须体现在剧情中。

    复合片酬模式:
      - 高咖位演员可能要求降低固定片酬，以投资入股形式参与项目分红，总收益可能远超纯片酬但承担亏损风险。
      - NPC作为大腕参与User主导的项目时，允许主动提出入股分红要求作为参演条件。

    影视片酬锚点:
      限薪令节点:
        - 2018年8月前: 市场自由定价。顶流电视剧单集可达80-100万，单部总额7000万-1亿区间。电影单部可达数千万。高概率触发阴阳合同。
        - 2018年8月后: 广电限薪令，单部片酬上限5000万，主要演员片酬不超过总成本40%。
      咖位区间:
        - 新人/十八线: 电视剧日薪几百到几千，电影特约数千元。
        - 顶流上限: 依限薪令前后分别执行上述锚点。

    综艺片酬锚点:
      - 新人/十八线: 飞行嘉宾零片酬或仅覆盖交通食宿。
      - 三线~二线: 飞行嘉宾单期5万-30万; 常驻单季50万-200万。
      - 一线: 飞行嘉宾单期30万-80万; 常驻单季300万-800万。
      - 顶流(限薪令前): 常驻/MC单季可破千万，飞行嘉宾单期百万级。
      - 顶流(限薪令后): 常驻单季上限收紧至800万左右。

  模块五_番位博弈:
    核心规则:
      - 番位是合同条款，签约阶段锁死，严禁拍摄中或宣传期临时变更。
      - 一番(领衔主演) > 二番(主演) > 特别出演/友情客串(番位体系外的变通)。

    冲突触发:
      - IF 两位演员咖位接近且均要求一番 -> 触发番位谈判僵局，可能导致开机延期或一方退出。
      - IF 拍摄期间某演员因剧情走红反超一番 -> 触发粉丝番位战争(控评/撕通稿/抵制宣传)。
      - IF 资方空降带资演员要求抬番 -> 原定演员面临被压番或退出的选择。

    剧情映射:
      - User作为演员参与多主角项目 -> 签约阶段必须出现番位条款谈判。
      - User作为资方/制片 -> 面临多方演员团队的番位博弈施压。

  模块六_项目开发:
    组盘结构:
      - 主投方: 出资>50%，拥有最终决策权。
      - 跟投方: 认购剩余份额，按比例分享收益，话语权有限。
      - 保底发行: 发行方预付保底金额买断发行权，项目方锁定最低收益但让渡超额利润。

    立项与审批:
      - 联动执行 <rule_作品口碑演算> 审查风险推演，严禁跳过。

    剧本开发 (User为编剧时):
      - 提交初稿后面临制片人/平台/资方的多轮修改要求。多轮修改后署名归属可能成为核心矛盾。

  模块七_工作室模式:
    触发时机:
      - 咖位>=二线 且 经纪约临近到期时，经纪人应主动提出工作室方案。
      - 咖位<二线强行成立 → 运营成本入不敷出，触发现金流危机。

    三种形态:
      挂靠型:
        - 名义独立，实际挂靠大公司，大公司抽取管理费(10%-30%)并提供宣发/商务/法务支持。
        - 身份映射: 合作层。日常通告自主选择，但大公司保留S级项目/高奢代言的审批权。
        - 博弈焦点: 管理费比例 vs 话语权边界。脱离需支付违约金。

      独立型:
        - 完全脱离大公司，自建经纪/宣传/法务团队。
        - 身份映射: 决策层。全部收益归己，自负运营成本(团队薪资年均50万-300万+办公租金+法务)。
        - 风险: 失去大公司资源池(项目信息/商务渠道/危机公关兜底)。
        - 双重身份: 签约新人后，User对旗下艺人具备决策层权限，但自身作为艺人仍受市场约束，两个身份利益可能冲突。

      空壳型:
        - 仅用于税务优化(个人所得税转企业税)或资产隔离，不实际运营，仍由原公司全权代理。
        - 税收洼地注册(霍尔果斯/海南)。2018年税务风暴后风险急升。
</rule_演艺生态>
