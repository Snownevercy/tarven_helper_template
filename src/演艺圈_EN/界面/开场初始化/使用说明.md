# 开场初始化界面 - 在酒馆中的使用方式

## 一、打包

在项目根目录执行：

```bash
pnpm build
```

或开发时保持监听：

```bash
pnpm watch
```

打包结果在：`dist/演艺圈_EN/界面/开场初始化/index.html`。

---

## 二、在酒馆中加载界面

开场界面是**前端界面**，会以 iframe 形式显示在**某一条消息楼层**里。你需要让这条消息的内容加载该 HTML，这样界面才会出现在该楼层，并且点击 Action 时会把变量写入**这一楼**的 MVU 变量。

### 方式 A：本地开发（localhost）

1. 确保已运行 `pnpm watch`，且端口 5500 可用。
2. 在酒馆中**发送一条新消息**，消息内容为下面这段（直接粘贴发送）：

```html
<body>
<script>
$('body').load('http://localhost:5500/dist/演艺圈_EN/界面/开场初始化/index.html');
</script>
</body>
```

3. 若酒馆/酒馆助手把该消息渲染为 iframe 并执行其中的脚本，则界面会出现在该消息楼层；此时在该楼层填表并点击 **Action**，变量会**直接写入当前楼层**的 MVU 变量。

### 方式 B：使用扩展/预设自动替换

若你使用酒馆助手的「界面-实时修改」等扩展，可把「你的界面打包路径」配置为：`演艺圈_EN/界面/开场初始化`，这样发送的某条消息会被替换成上述 `load(...)` 形式，从而在该楼层加载开场界面。

### 方式 C：线上地址（如 GitHub + jsDelivr）

若你把 `dist/` 部署到 GitHub 等，可使用线上 URL，例如：

```html
<body>
<script>
$('body').load('https://你的域名/dist/演艺圈_EN/界面/开场初始化/index.html');
</script>
</body>
```

（具体 URL 以你实际部署路径为准。）

---

## 三、使用流程建议

1. **选好角色卡**：使用已配置 MVU 变量框架 + 演艺圈_EN 世界书/变量的角色卡。
2. **开新聊天**：新建一个聊天，保证会走 MVU 初始化（initvar 等）。
3. **发一条“开局”消息**：内容为上面「方式 A」中的 HTML（或通过扩展替换），发送后该消息楼层会加载开场界面。
4. **等界面出现**：界面加载后会等待当前楼层存在 `stat_data`（MVU 已初始化），然后显示表单。
5. **填表并点 Action**：填写艺人档案、开机信息等，点击 **Action**，脚本会**直接把表单内容写入当前楼层的 MVU 变量**（不经过发送提示词）。
6. **继续对话**：变量已写入后，可在此聊天中正常发消息，让 AI 根据已初始化的变量生成开场或后续剧情。

---

## 四、注意事项

- **必须在该楼层加载**：界面通过 `getCurrentMessageId()` 确定「当前楼层」，因此界面必须是在「要写入变量的那条消息」里加载；否则会写到别的楼层。
- **MVU 与 initvar**：界面会等待当前楼层出现 `stat_data` 再启用按钮；若该聊天/楼层尚未被 MVU 初始化，可稍等或先发一条消息触发初始化后再用开场界面。
- **只写一次**：点击 Action 后按钮会变为「Cut!」并禁用，避免重复写入；若需重新初始化，可刷新页面或重新加载该界面。
