# 关系网头像命名规则

本目录的图片会被 `状态栏_档案/index.ts` 自动加载，不需要手动在代码里写导入。

## 推荐命名（主规则）

- `人物名_01.png`
- `人物名_02.webp`
- `人物名_03.jpg`

同一个人物放多张图时，按文件名排序后显示，点击头像可在弹窗里切换上一张/下一张。

## 兼容命名

脚本同时兼容：

- `人物名--01.png`
- `人物名@@立绘A.png`
- `人物名_1.png`
- `人物名-2.png`
- `人物名(便服).png`

如果文件名无法识别人物名，则会用整个文件名（去扩展名）作为人物名。

## 示例

- `宁浩__01_正装.svg`
- `宁浩__02_休闲.svg`

当 MVU 中 `network.relationshipBook` 出现键名 `宁浩`，就会自动显示这些头像并支持切换。
